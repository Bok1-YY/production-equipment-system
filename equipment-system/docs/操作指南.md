## 一、进入系统与登录

### 1.1 三种进入方式

| 方式 | 适合谁 | 怎么进 |
|---|---|---|
| 手机 App（推荐） | 所有人，尤其是车间现场 | 安装公司发放的 Android 安装包（APK），桌面点「优胜美设备管理」图标 |
| 手机浏览器 | 临时没装 App | 浏览器打开管理员提供的系统地址 |
| 电脑浏览器 | 管理员、办公室人员 | 浏览器打开同一地址 |

电脑和手机是**同一套系统、同一套账号、同一份数据**，在哪边操作都一样，随时可以换着用。

### 1.2 安装手机 App

1. 用手机浏览器打开管理员提供的 APK 下载地址（一般为 `系统地址/downloads/ysm-equipment-mobile-test.apk`），或扫管理员提供的下载二维码；
2. 下载完成后点击安装。手机若提示「未知来源应用」，按提示允许本次安装；
3. 首次打开 App 时，**请允许「通知」权限**——技术员和管理员的新报修、技改任务提醒都靠它；
4. 技术员日常还会用到**相机**权限（巡检拍照、完工拍照），首次拍照时按提示允许即可。

> 手机和服务器必须在**同一网络**（公司 Wi-Fi）下，或使用管理员提供的公网地址。打开 App 显示「网页无法打开／无法连接」时，先检查手机 Wi-Fi 是否连对，再确认服务器已启动。

### 1.3 登录

1. 输入**工号**和**密码**（都由管理员分配），点「登录」；
2. **首次登录会强制修改密码**：初始密码只能用这一次，改完才能进入系统。新密码**至少 12 位**，请设置成自己记得住、别人猜不到的组合；
3. 忘记密码：找管理员在「成员管理」里**重置密码**，你会拿到一个新的一次性密码，登录后同样强制再改一次。

登录状态最长保持 12 小时，之后需要重新登录。

### 1.4 界面通用元素

- **顶部导航条**：左右滑动（手机）或直接点击切换功能页。你能看到哪些页面由你的级别决定；
- **右上角「更多」**：修改密码、退出登录；手机 App 里还有「服务器」（查看当前连接的服务器地址，一般不需要动）；
- **右下角「扫码」浮动按钮**：扫设备铭牌或工序二维码，普工直接进报修，技术员会出现「登记巡检 / 报修」二选一；
- **各页面的「刷新」按钮**：数据看起来不新时点一下。

## 二、角色与权限一览

每个账号属于一个级别，级别由管理员指定。

| 级别 | 角色 | 能看到的页面 | 核心权限 |
|---|---|---|---|
| 一级 | 普工 | 维修报修 | 扫码报修、撤回自己的误报、查看**自己报修的**工单进度、完工后给技术员打分、没修好可重新报修 |
| 二级 | 技术员 | 总览、维修报修、设备巡检、结构化点检、设备保养、设备台账（只读）、产线组合（只读）、技改任务（自己被分配的）、运营报表 | 抢单维修并结单、日常巡检、执行点检／保养任务、执行技改任务；只能推进**自己接的**工单；只能看到**自己的**综合评分 |
| 三级 | 管理员 | 全部页面 | 工单指派／转派／取消、设备台账与产线组合维护、发布和审核技改任务、点检保养模板与计划、故障代码维护、服务评价查看、成员管理、操作日志、运营报表 |

> 权限在服务器端强制校验。页面上看不到的功能，换个入口也做不了，不用担心误操作越权。

## 三、普工操作指南（报修、撤回、评价）

普工登录后直接进入「维修报修」页。日常只需要掌握四件事：**报修、撤回、看进度、评价**。

### 3.1 扫码报修（最快）

1. 点右下角「扫码」，对准设备上的**铭牌二维码**；
2. 设备和所在工序自动填好；
3. 用一句话说清楚哪里不对劲，例如：`3号挤出机不出料了`；
4. （可选）如果界面出现**常见故障快捷按钮**（如「整机无法启动」「漏油」），直接点一个，那句话都可以不打；
5. （可选／有时必填）拍张现场照片。某些故障类型（如漏油）要求必须拍照，按钮上会提前标出「需拍照」；
6. 如果设备停机了，勾选「停机」；
7. 提交。完成，接下来等技术员接单。

### 3.2 手动选设备报修（扫不了码时）

码磨掉了、手机扫不出来，就手动选：

1. 在报修页按「车间 → 产线 → 设备」一级一级缩小范围；设备名字带着**工位顺序和现场叫法**（比如「03 · 1#开槽分切多片锯」），跟你站在线上看到的顺序一致；
2. 也可以直接在搜索框输入设备编号、现场名称或类型，跨车间直接搜；
3. **实在说不清是哪台设备**：选「无法判断具体设备」，再选一下工序，写清现象即可——由到场的技术员来认设备。

> 故障分类**不需要普工选**。你只管把现象说清楚，分类由到场看过的技术员确认。

### 3.3 撤回误报

报错设备、机器自己恢复了、误操作提交——在**技术员到场之前**都可以撤回：

1. 打开自己那张工单，点「撤回」；
2. 必须填一句撤回原因，提交即可。

技术员**已经到现场**就不能再撤回了（人已白跑，请当面沟通）；这种情况下只有管理员能取消工单。

### 3.4 查看进度

工单列表里只显示**你自己报修**的单子。打开详情可以看到当前走到哪一步：

```
报修 → 已接单 → 已到场 → 维修中 → 待试运行 → 已完成
```

### 3.5 评价（工单完成后）

维修完成后，你的工单上会出现「待评价」标记：

1. 打开工单，对**维修质量、服务态度、响应速度**三项各打 1～5 星；
2. 可以补充文字和照片（不会写就拍照）；
3. 一张工单只能评一次，但**随时可以修改**。

**请放心如实打分**：技术员看不到单条评价的内容、照片，也看不到是谁评的，只能看到自己的综合平均分。评价是选填的，不评价也不影响工单完成。

### 3.6 重新报修（没修好）

已完成的工单如果问题又出现了：打开原工单点「重新报修」，设备和故障分类自动沿用，新单会标注「重报自 WO-xxx」。几天内的重报本身就是「上次没修好」的信号，管理员看得到。

## 四、技术员操作指南

### 4.1 维修工单：从接单到结单

工单详情顶部有一条**步骤条**，显示当前第几步、还差几步。每一步只需要点一个写着动作名字的按钮。

```
待接单池 → ①我接这单 → ②我到现场了 → ③开始维修 → ④转试运行 → ⑤结单
```

**① 接单**：在待接单池点「我接这单」。接了单就是你负责，**别的技术员不能推进你的单**；确实要换人，让管理员转派。

**② 到场**：到现场后点「我到现场了」。系统分开记录「报修到接单」和「接单到到场」的时长，所以接单≠到场，到了再点。

**③ 核对报修信息（到场后、开工前）**：这一步要确认两件事——
- **实际故障设备**：普工报的设备不对或没选设备，在这里改成实际那台；
- **故障分类**：从三级故障代码（类别→部位→现象）里选，普工的原话仍会保留在补充说明里。

两项都确认后才能点「开始维修」。开工后这一块默认不再显示；确实核对错了，用「返回」按钮回到这一步再改。

**④ 维修中**：填写**诊断原因**（最终判断的故障原因）和**维修方法**（实际怎么修的），登记**使用零件**（填错可删除重填），需要时拍**完成照片**。等配件、外协时可以切换到对应状态，之后可回到「已到场」重新开工。

**⑤ 待试运行**：点「转试运行」后，只需要填**试运行结果**，三选一：
- `正常运行` —— 可以结单；
- `可运行但仍存在问题` —— 必须写清遗留问题，才能结单；
- `无法运行` —— 不能结单，请返回维修。

发现维修资料填错了？点「维修资料有误？返回维修」回去改。

**⑥ 结单**：结单前系统会做「结单前检查」，**五样缺一不可**：

| 必填项 | 缺了会怎样 |
|---|---|
| 试运行结果 | 检查行直接定位到试运行选项 |
| 实际维修的设备 | 返回核对阶段补选 |
| 故障代码 | 返回核对阶段补选 |
| 诊断原因 | 自动退回维修中并聚焦对应输入框 |
| 维修方法 | 同上 |

缺项提示本身就是按钮，点它直接跳到要补的地方。补齐后点「结单」，**不需要管理员在场**——验收由报修人的评价承担。

> 巡检转来的维修工单还必须**现场实时拍摄**「维修完成照片」（自动加设备、维修人、时间水印），相册旧图无效。

### 4.2 日常巡检

「设备巡检」刻意做得很轻：**扫码选设备 → 拍照 → 写发现**，没有逐项打勾的表。

1. 扫设备铭牌，选「登记巡检」；
2. **必须用摄像头现场拍至少一张照片**（自动加设备、巡检人、时间水印；换了设备要重拍）；
3. 写清发现了什么、怎么处理的；正常情况用快捷按钮（运行正常／已润滑保养／已紧固）；
4. 当场解决不了的问题点「**转维修工单**」直接开单，巡检发现自动带进工单说明，两边互相关联。

巡检记录会进设备档案的「巡检记录」标签页。

### 4.3 点检与保养任务

管理员建好模板和周期计划后，到期任务会自动出现在「结构化点检」和「设备保养」页：

1. 打开到期任务，**逐项**填写结果；数值项直接填数，超出上下限系统自动判「异常」；
2. 异常项两种处理：当场说明并关闭，或**转维修工单**；
3. 有拍照要求的项目按提示拍照；
4. 全部填完提交。到期任务不会重复生成，做完一条少一条。

### 4.4 技改任务（被分配时）

管理员发布技改任务后，你会收到通知（手机通知栏 + 系统内）：

1. **确认方案**：打开任务，查看目的、验收标准和技术图纸，点「确认已阅读本版方案」。**所有执行人都确认后**主负责人才能继续；
2. **到场 → 开始施工**（主负责人操作）；
3. **逐项施工**：每个项目填写**实际执行结果**；要求拍照的项目必须**现场拍摄至少一张完工照片**；
4. **发现图纸与现场不符**：点「上报偏差」写明情况，任务进入待修订，等管理员发新版方案后**所有人重新确认**（未改动项目已填的结果和照片保留）;
5. **提交审核**（主负责人操作）：全部项目完成后提交，等管理员审核；
6. 管理员可能「退回整改」——按批注补做后再次提交；「审核通过」后整单生效，设备和产线数据自动更新。

> 你只能看到**分配给自己**的技改任务。

### 4.5 通知

- 手机 App 登录后自动开启业务通知：**新报修**（待接单池有新单）和**技改任务**（分配、修订、审核结果）；
- 通知栏点击技改通知会**直接打开对应任务**并自动标记已读；
- 收不到通知时：检查系统设置里是否允许了本 App 的通知；App 或手机重启后，打开一次 App 即恢复。

### 4.6 我的评分

「总览」页可以看到**自己的**综合平均分和三个维度（维修质量／服务态度／响应速度）得分，用来了解自己哪方面需要改进。单条评价内容、照片、评价人对技术员**完全不可见**。

## 五、管理员操作指南

### 5.1 成员管理

- **开户**：填工号、姓名、级别（1 普工／2 技术员／3 管理员）。系统自动生成初始密码，**只在创建成功那一次显示**，请当面或私下交给本人；对方首次登录强制改密；
- **重置密码**：本人忘记密码时使用，生成新的一次性密码，并立即踢掉该账号的已有登录；
- **调级别／停用**：改动即刻生效，对方已登录的会话立即失效。账号**只能停用不能删除**（保护审计日志），最后一个启用的管理员不能被停用或降级。

> 建议：至少保持两名真实管理员；技改任务由不同管理员分别**发布**和**审核**。

### 5.2 设备台账

- **建档**：新设备录入标准名称、类别、类型代码、关键规格等，系统按「类型＋关键规格」自动分配永久设备码（如 `YSM-EXT-135-0001`）。**设备码、类型、关键规格建档后锁定**；名称、现场别名、品牌、负责人等随时可改；
- **Excel 整批导入**：页面下载台账模板 → 填写 → 上传预览 → 确认导入。**只要有一行「待核实」或错误，整批都不写入**，改完再传；
- **管理类型**：维护设备类型代码目录（新增、改名；已被使用的类型有保护）；
- **打印铭牌**：单台点行内「铭牌」；整线点「批量打印铭牌」选车间和产线，铭牌按工位顺序排好，拿着一叠走一条线贴完。
  > ⚠️ 批量打印前必须确认系统的公网／内网访问地址（`PUBLIC_BASE_URL`）已配置正确，否则二维码里存的是本机地址，手机扫了打不开。打印页有红色警告提示时不要印。
- **设备状态**：在用／闲置／停用／报废由你手工维护；「已报修」「维修中」由工单自动推算，不能手工选。维修期间改状态，改的是「结单后回到的状态」。

### 5.3 产线组合

- **树维护**：逐级创建车间→产线→工序→机位；误建的**空**分支可整枝删除（存在任何设备安装、变动、工单或巡检历史时系统会阻止——历史数据绝不因删结构而丢失）；正常退役用「停用」；
- **组合导入**：下载组合模板，旧表整理成「一行一个机位」，上传预览无误后整批导入。设备匹配顺序为**永久编码 → 原资产编号 → 品牌＋出厂编号**，绝不按名称模糊匹配；匹配不上的行必须提供名称＋类别＋类型代码，由系统发新码。同一个文件不能重复导入两次；
- **正式运行后的安装／移动／拆除／替换**：一律走「技改任务」，不在树上直接改。

### 5.4 技改任务（发布与审核）

**发布**：

1. 「技改任务」页填写标题、改造目的、验收标准、优先级、计划时间，指定**主负责人**和协作技工；
2. 「新增一项」编排项目：设备项目（安装／移动／拆除／替换／档案改造）或结构项目（新增／改名排序／调整所属／启停／安全删除）；免拍照的项目必须写明原因；
3. 保存草稿 → **上传至少一份技术文件**（PDF、Office、图片、DWG/DXF、ZIP）→ 「发布」；
4. 发布后所有执行人须确认方案。需要改方案就「修订重发」，旧确认作废、需重新确认，但未改项目的施工证据保留。

**审核**：

- 技工提交审核后逐项查看结果与完工照片；
- 「退回整改」需写明原因；「审核通过」时系统重新校验现场状态，并在**一个事务**里应用全部项目——任何一项冲突（如目标机位已被占用）都会**整单回滚**，不会出现改了一半的中间状态；
- 执行期间受影响设备显示「改造中」、产线显示「调整中」（维修状态优先）。

任务在任何未结束阶段都可以「取消」。

### 5.5 工单管理

- **指派／转派**：可直接把待接单工单派给某技术员，或把在修的单转给别人（转派留痕，不打断维修阶段）；
- **取消**：任何未结束阶段都能取消（技术员不能取消，普工只能在到场前撤回自己的单）。

### 5.6 点检与保养

- 在「结构化点检」「设备保养」建**模板**：逐项设置检查类型、标准、数值上下限、异常拍照要求；保养模板必须指定一／二／三级；
- 建**计划**：对象选设备或工序，周期支持每天、每周、间隔天数、固定一次、手工下发；到期自动生成任务且不重复；
- 跟踪完成率看「运营报表」。

### 5.7 故障代码

三级结构：**类别 → 部位 → 现象**。每条可配置：处理建议、默认紧急程度、默认停机、必须拍照、是否进普工的「常见故障快捷按钮」。

> ⚠️ 系统预置的 23 条带「待确认」标记，是按旧系统整理的建议值。**请设备科尽快核对**——技术员结单只能从这个列表选，列表不准直接影响故障统计。已被工单使用的代码只能停用不能删除。

### 5.8 服务评价

查看全部评价（含文字、照片、评价人）和技术员综合排行。此页只有管理员可见。

### 5.9 运营报表

按日期范围统计：平均响应时长、平均维修时长、停机、重复报修；产线故障、故障类别、设备故障排行均可**下钻到具体工单**；全部结果可**导出 Excel**。

### 5.10 操作日志

系统内所有关键操作（谁、什么时候、干了什么）自动留痕，可在「操作日志」页查询审计。

## 六、通用功能说明

### 6.1 设备档案

台账任意一行、或产线树上设备节点，点「档案」打开抽屉，四个标签页：

| 标签页 | 内容 |
|---|---|
| 基本信息 | 档案字段（管理员可编辑，技术员只读） |
| 位置变动 | 何时装在哪个机位、何时搬走、哪张单、谁提交谁审核 |
| 维修记录 | 历次故障现象、诊断、维修方法、试运行结果、停机时长、更换零件 |
| 档案修改 | 谁在何时把哪个字段从什么改成什么 |

顶部常驻统计：维修次数、未结工单、累计停机分钟、更换零件数、位置变动次数、上次维修时间。

### 6.2 设备状态一览

| 状态 | 维护方式 |
|---|---|
| 在用 / 闲置 / 停用 / 报废 | 管理员手工维护 |
| 已报修 | 系统自动：普工提交报修后 |
| 维修中 | 系统自动：技术员开工后，直到结单或取消 |
| 改造中（设备）/ 调整中（产线） | 系统自动：影响生产的技改任务执行期间 |

状态由**未结工单实时推算**：一台设备挂两张工单时，关掉一张不会提前恢复。产线树上维修中的机位整行标黄。

### 6.3 二维码与铭牌

- **设备铭牌**：一台一码，印设备编码、现场叫法、标准名称、品牌型号。**刻意不印位置**——设备会搬，位置扫码看系统里的当前值；
- **工序二维码**：贴在产线入口或巡查点，扫码查看并筛选该工序设备。

### 6.4 照片规则

- 每条记录最多 **6 张**，单张不超过 **2MB**，系统自动压缩到长边 1600 像素；
- **巡检照片**和**巡检转维修的完成照片**必须现场实时拍摄，自动加水印，相册旧图无效；
- 报修／评价／维修过程照片可拍摄或从相册上传；
- 照片可见性跟随业务：评价照片只有评价人和管理员可见。

## 七、常见问题（FAQ）

**Q1：打开 App 显示「网页无法打开」或一直转圈？**
手机没连公司 Wi-Fi、或服务器没启动。先确认手机 Wi-Fi，再找管理员确认服务器状态。管理员侧：确认启动器窗口在跑、地址与 APK 内置地址一致。

**Q2：忘记密码怎么办？**
找管理员重置。重置后拿到一次性新密码，登录后系统强制你再改一次。

**Q3：手机收不到新报修／技改通知？**
① 系统设置里允许本 App 的通知权限；② 打开一次 App 让通知服务重新启动；③ 小米等机型把 App 加入「自启动／省电白名单」，避免后台服务被杀。

**Q4：扫铭牌二维码打不开页面？**
铭牌可能是在访问地址配置错误时打印的（码里存了本机地址）。找管理员确认 `PUBLIC_BASE_URL` 配置后重新打印该批铭牌；急用时先手动选设备报修。

**Q5：为什么点「结单」被拒绝？**
差五必填之一：试运行结果／实际设备／故障代码／诊断原因／维修方法。看「结单前检查」的红色缺项行，点它直接跳到要补的地方。巡检转来的单还要现场拍完工照片。

**Q6：设备工单都关了，状态怎么还是「维修中」？**
这台设备还挂着**另一张**未结工单。状态由全部未结工单推算，全部结束才恢复。

**Q7：报修撤不回了？**
技术员已到场就不能撤回。请当面沟通，需要作废时由管理员取消工单。

**Q8：普工为什么看不到别人的工单／台账？**
设计如此：一级账号只看自己报修的单。需要更多权限找管理员调级别。

**Q9：评价会被技术员看到吗？**
不会。技术员看不到评价内容、照片和评价人，只能看到自己的综合平均分。请如实打分。

**Q10：技改任务里为什么不能开工？**
所有执行人（主负责人＋全部协作技工）都点了「确认已阅读本版方案」之后，主负责人才能到场开工。方案被修订后需要**全员重新确认**。

**Q11：导入 Excel 一直不成功？**
预览里只要有一行错误（含「待核实」），整批都不会写入——这是防止半批数据入库的保护。按预览提示改完那几行再传。组合文件重复导入会被文件去重拦截。

## 八、使用注意事项

1. **一人一号，不共用账号**——工单归属、评价归属、审计日志都跟着账号走，共用账号出了问题说不清；
2. **密码自己保管**，至少 12 位；管理员和系统都查不到你的明文密码；
3. 公用电脑上用完请点「更多 → 退出」；
4. 手机换新或离职时告知管理员**停用账号**（停用即刻生效，历史记录保留）；
5. 巡检、完工照片必须**现场实拍**，这是留证要求，相册旧图系统不认；
6. 报修时**说清现象**比选对分类重要——分类交给到场的技术员；
7. 看到界面上「待确认」「需拍照」「待评价」等标记，按提示处理即可，系统会在关键步骤把该做的事拦在前面。
